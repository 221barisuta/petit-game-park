## 1. #3 再戦バグ修正 — Must（最優先）
### 原因
再戦成立時、サーバーは先後を入れ替える（席オブジェクトをswap）が、**入れ替え後の席をクライアントに通知していない**（新しい `assigned` を送っていない）。クライアントの `state.seat` は `assigned` 受信時しか更新されないため、再戦後に**自分の色が古いまま**になり、サーバーとクライアントで手番判定がズレて**両者とも打てない＝再戦が動かない**。

### 修正
- サーバーの再戦処理で席が変わった各接続に、**新しい `assigned`（新 seat ＋ token）を送る**。クライアントは既存の `assigned` ハンドラで `state.seat` を更新するので、それで直る。
- 先後入替自体は公平性のため維持。トークンは各プレイヤーに紐づいたまま（色だけ入替）。
- `server.test.mjs` に「再戦後に各接続のseatが正しく再割当され、新assignedが送られる」テストを追加。

## 2. #4 オンライン待った — Must
### ルール（合意不要・レース無し）
- **「待った」は直前に着手した側だけが、相手がまだ着手していない間だけ**実行できる。
  - 自分が打つと相手の手番になる。その瞬間「取り消せる最新手」を持つのは直前に打った自分だけ。
  - **相手（手番側）の待ったボタンは無効（グレー）**。よってどの瞬間も押せるのは片側だけ＝レースが発生しない。
  - 相手が打った瞬間、自分の待ったは無効化（もう直前手ではない）。
- 取消はサーバーが権威的に実行し、**相手に通知**（「あいてが まったを しました」トースト＋必要ならログ）。

### 実装
- サーバー：新メッセージ `undo`。検証＝requesterが着席／対局中（未決着）／`g.last` の石が requester の色／現在 requester の手番でない（＝直前に打ったのが requester）。OKなら `g.board[g.last]=null`、`g.last` を1手前へ（履歴必要なら前手indexを保持。無ければ -1）、`g.turn=requester`、`broadcastState()` ＋ 相手向け通知。観戦者・未該当は無視。
- クライアント：待ったボタンの有効条件＝`seated && 対局中 && board[last]===myseat && turn!==myseat`。押下で `undo` 送信（サーバー再検証）。相手側は通知トースト表示。
- 取り消せるのは**直前1手のみ**（ローカルの待ったと同じ粒度）。

## 3. #5 着手UI（タップ仮置き→再タップ確定）— Must
- 盤タップ時、いきなり確定せず**仮置き（プレビュー石・半透明の自色）**を表示。
- **同じ交点をもう一度タップで確定**（move送信）。**別の交点をタップすると仮置きがそこへ移動**。確定ボタンは作らない。
- 仮置きは「手番が変わった／待った／オンライン退出」でクリア。自席・自手番のときのみ仮置き可能。
- 対象は**オンラインの盤タップ**（Must）。ローカル五目（2人/CPU）にも同方式を展開すると一貫する（Should・任意）。
- マウス操作時はホバーでプレビュー→同交点クリックで確定でよい（入力種別に応じて自然に）。

## 4. #6 LINE招待 — Must
- 入室UIの共有導線（現状：📋コードコピー／🔗リンクコピー）に **「LINEで しょうたい」ボタンを追加**。既存のコピーは残す。
- 動作：`https://line.me/R/msg/text/?` に「お誘い文＋部屋リンク」を URLエンコードして付与し、別タブ/アプリで開く（例文「『五目並べ』いっしょにやろ！ <roomLink>」）。
- モバイルのLINEアプリ起動を想定。デスクトップで開けない環境でも既存のリンクコピーで代替できるので致命的でない。

## 5. #8 通算勝敗＋ホバー履歴 — Must
- 同じ部屋セッション内の**シリーズ成績**（1局目〜N局目）を保持・表示。
- 席は毎局入れ替わるので、**色ではなくプレイヤー識別（席トークン）で勝者を記録**する（色集計だと入替で破綻）。
  - サーバー：`series: [{game:1, winnerToken | null(draw)}]` を持ち、各局決着時に追記。再戦リセットでもトークンは保持されるので識別は安定。state にも `series` を載せて配信。
- クライアント：自分のトークンと相手トークンを突き合わせ、**通算（例「あなた 2 - 1 あいて」、引分は別表記）**をオンラインバーに表示。
- **ホバー（PCはマウスオーバー／スマホはタップで展開）で 1局目〜N局目の勝敗一覧**を表示（「1局目: あなたのかち / 2局目: あいてのかち / 3局目: ひきわけ …」）。
