## 1. 背景・目的
- 三目並べ（ox）で導入した `type:'versus'` 基盤の上に、2本目の対戦ゲームとして五目並べを追加する。
- Ver1.0は **1ブラウザ・2人ローカル対戦** のみ（CPUなし）。将来CPUを足しやすい構造にする。

## 2. 採用方針
- **コア改変は原則ゼロ。** 既存の `type:'versus'` 分岐にそのまま乗せる。三目並べ（ox）の実装を雛形にする。
- もし versus 分岐の微調整が必要になっても、既存3ゲーム（tea/lane/spot）と ox の挙動を壊さない範囲に限定する。

## 3. 機能要件

### Must（Ver1.0）
- [ ] 15×15 の盤（連珠規格）。石は格子の**交点**に置く（15×15＝225点）
- [ ] 2人交互（黒●／白○ または 同系の2色石）
- [ ] 縦・横・斜め（4方向）で **5つ以上**並んだら勝ち
- [ ] 勝った5連をハイライト
- [ ] 盤が全部埋まって勝者なし＝引き分け（実質ほぼ起きないが判定は用意）
- [ ] リセット／もう一度
- [ ] 手番表示（HUD：「●のばん」「○のばん」、決着で結果文言）
- [ ] スマホ対応（縦型 420×740 ステージ内に収め、タップで最寄り交点に着手）
- [ ] 既存4ゲーム（tea/lane/spot/ox）の挙動・スコア・ランキングに影響を与えない

### Should
- [ ] 直前の着手位置マーカー（盤が密なので「今どこに置いたか」を示すと親切）
- [ ] 簡単な遊び方（howto）表示

### Could（将来）
- [ ] CPU対戦。`getGomokuCpuMove(board, mark)` を差し込むだけにする
- [ ] 連珠の禁じ手（三々・四々・長連）。Ver1.0では**実装しない**（カジュアル運用）

## 4. 技術仕様

### 盤・座標
- 内部状態 `board` は長さ225（15×15）の1次元配列、空き=`null`、石=`'black'`/`'white'`（または `0/1`）。**ox の checkWin と表現を揃える方針（空き=null）**。
- 描画は 420幅ステージに収まるよう、盤に左右マージンを取り、15×15の格子線＋交点に石を描く。1マス約26〜28px想定。
- タップ座標 → 最寄り交点へスナップして着手（ヒットテストの許容半径を設ける）。密なので誤タップ対策に**着手確定前の薄いプレビュー**を入れてもよい（任意）。

### 勝敗判定（純関数）
- `checkGomoku(board, lastIndex) -> {winner, line}` を **トップレベルの純関数**として実装。
  - lastIndex から4方向（横・縦・右下がり・左下がり）に同色連続数を数え、**5以上**で勝ち。
  - 勝ちなら `line` に5連（以上なら端から5点でよい）の座標を返す。ox の `checkWin` と返り値の形（`{winner,line}`）を合わせる。
- 副作用なし。将来 `getGomokuCpuMove(board, mark)` を差し込めるよう、着手は `place(index)` に集約し手番交代を1箇所に。

### registerGame
```
registerGame({
  id:'gomoku', emoji:'⚫', title:'ごもくならべ', desc:'2人で あそぶ 五目ならべ',
  color:'#cdb892', type:'versus',   // duration は付けない
  howto:[['👆','こうてんを タップして いしを おく'],['🏆','タテ・ヨコ・ナナメに 5つ ならべたら かち！']],
  create(ctx){ ... }
})
```
- 既存コントラクト通り `onDown(x,y)` で受ける（自前 addEventListener 禁止）。`draw(g)`／`hudInfo()`／必要なら `update(dt)` を実装。決着後タップでリセット。

## 5. UI/UX
- ゲーム選択：既存カードに「ごもくならべ」を追加（既存カードCSS流用、ox と同じ versus 扱い）。
- 盤・石・ハイライトは既存の手描き風トーン・配色を流用。

## 6. 非機能要件
- 対応：Chrome / Safari 最新、モバイル必須、PWAは単一ファイルのため sw.js 変更不要。
- パフォーマンス：225点・1着手ごとの局所走査なので軽量。

## 7. テスト観点
- 自動：`checkGomoku()` の純ロジック（横/縦/両斜めの5連、6連=長連も勝ち、端・角での誤検出なし、未決着）
- 手動：4方向の5連勝利・引き分け（埋め切り）・リセット・手番交代・決着後の誤タップ無効・直前手マーカー
- 回帰：tea/lane/spot/ox が従来通り（特に ox と versus 分岐を共有するので ox の回帰必須）
- 表示：スマホ実機で15×15が崩れず、タップが意図した交点に入るか
