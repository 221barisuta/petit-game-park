# spec-mahjong-ui — 麻雀なぜきり道場 UI仕様（フェーズ管理）

対象: index.html 内 `registerGame({id:'mahjong',…})` ブロック。
本ファイルはフェーズごとに追記していく（フェーズ1: 2026-07-02 / PR feature/mahjong-ui1）。

---

## 現状仕様（フェーズ1着手前 = PR #29 時点）

### ゲーム構成
- **1人用の通し対局**（何切る単発局面ではない）: 配牌13枚→ツモ→打牌を流局(壁14枚残し)/和了/放銃まで繰り返す。
  相手は CPU 1人（同じ分析器で打牌・リーチ・ロンあり）。1打ごとにコーチが採点し、局終了後に SS〜C レポート。
- 進行フェーズ: `draw → select → fb(フィードバック) → cpu → … → end → report`。

### 牌の内部表現（フェーズ2/3 でもこのまま使う）
- **tileId: int 0-33** … 0-8=萬1-9 / 9-17=筒1-9 / 18-26=索1-9 / 27-33=東南西北白發中。
- 手牌は **int[34] 枚数配列**。表示名は `MJ.NAMES[tileId]`（'1萬'〜'9索'・'東'〜'中'）。
- 局状態 `R`（mjRoundNew）: `wall`(山・末尾からpop) / `my`,`cp`(int[34]) / `myRiver`,`cpRiver`(河) /
  `S`,`Sc`(安全度カウンタ) / `myRiichi`,`cpRiichi` / `lastDraw` ほか。ロジックはUI非依存（ヘッドレステスト可能）。

### 旧UI（フェーズ1で置換した部分）
- 牌: 白カード+「数字+萬/筒/索」テキスト、字牌1文字。河は12枚×2段。背景は淡い単色。
- 入力: onDown のみ（牌タップ=選択、同じ牌を再タップ=打牌確定）。

## フェーズ1仕様（見た目・操作性 / 本PR）

### 1. リアル牌描画 `mjRenderTile(g, tileId, x, y, w, h, opts)`
- canvas のみ（画像・新規ファイルなし）。手牌/河/ルーペ/候補行のすべてがこの1関数を使う。
- `opts`:
  - `sel` … 選択強調（枠オレンジ・面クリーム）
  - `ghost` … 薄表示（リーチ宣言中の「切れない牌」。旧 `dim` は alias）
  - `gray` … グレーアウト（**ツモぎり牌の河表示**。面・図柄とも灰色化）
  - `back` … 裏面（緑ベタ。**フェーズ2の他家手牌用**に先行実装）
- 図柄: 萬子=漢数字(五は赤)+「萬」/ 筒子=伝統配置の丸ピップ(`MJ_PIPS`、1筒は大円・5筒中央は赤)/
  索子=竹スティック(1索は様式化1本+赤帯・5索中央は赤)/ 字牌=漢字(發=緑・中=赤・白=青枠の空白)。
- 立体感: 下面(厚み)を描いてから面を重ねる。角丸・細枠。

### 2. ルーペ操作
- 牌タップ（選択）で盤中央 `LP={x:105..315,y:340..536}` に **約3倍の拡大牌+牌名+操作ガイド**を表示。
- 確定: **同じ牌を再タップ / ルーペをタップ / 上フリック**（`onFlick` で dy<-40 かつ縦優勢）。
- 解除: **他の場所タップ / Esc**（`onKey`）。選択牌は手牌側でも浮き上がり+ハイライト維持。

### 3. 卓の雰囲気
- オフスクリーン canvas `FELT`（生成1回・毎フレーム drawImage）: 緑フェルトのラジアルグラデ+
  ノイズ1600点（布目）+木目調の縁（2重ストローク+ハイライト/シャドウ線）。

### 4. 河レイアウト
- **1行6枚で改行・4段(24枚)のグリッド**。`river(g, list, x0, y0)` は開始座標を引数に取る
  （フェーズ2で4人分の河を並べる前提。自河=430、CPU河=74、x は中央寄せ `RVX`）。
- 局は最長で片側約48打まで続き得るため、**25打目以降は最新24枚のみ表示し、
  左肩に「+N」で省略数を出す**（レイアウト崩れ防止。安全度計算は S カウンタ基準なので影響なし）。

### 5. 手出し／ツモぎり
- 河は `{t: tileId, ted: boolean}` の配列に変更。`ted=true`=手出し（直前の自摸牌 `R.lastDraw` 以外を切った）。
  CPUの河にも記録（**フェーズ3の手牌読みの土台**）。
- 表示: **ツモぎり牌をグレーアウト**（手出しは通常表示）。ボタン「🌗ツモぎり」でON/OFF、
  `pgp2_mj_tedashi` に永続化（既定ON）。
- 注意: 値ベース表現のため「自摸牌と同種の牌を手牌から切った」場合もツモぎり扱い（シミュレータの既知制約）。

## フェーズ2予定（別発注・参考）
- 4人打ちエンジン化（山・配牌・周回進行）+ 場風/親子 → CPU/ヒントの打牌優先度へ反映。
- 他家手牌は `mjRenderTile(…,{back:true})` を使用。河は `river()` の座標引数で4人分描画。

## フェーズ3予定（別発注・参考）
- 他家の手出し牌列（`cpRiver[].ted`）から手牌読み+対象牌の残り枚数で
  ノーチャンス/ワンチャンス判定を表示。安全度テーブル(MJ_SAFETY)と `S`カウンタを流用。
