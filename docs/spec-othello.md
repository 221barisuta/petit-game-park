# オセロ (リバーシ) 仕様 — spec-othello.md

プチゲー★パーク (`index.html` 単一ファイル) の対戦ゲームとして追加するオセロの仕様。
Ver1.0 は **1ブラウザ・2人ローカル対戦のみ**(CPU/オンラインなし)。既存の五目並べ
(`id:'gomoku'`) / 三目並べ (`id:'ox'`) と同じ `type:'versus'` パターンに準拠する。

## 1. 方針
- `type:'versus'` 基盤は既存。コア改変はゼロ、`registerGame({id:'othello',...})` の追加が主体。
- gomoku/ox のスタイルを踏襲: 純関数でロジックを分離 / `place()` に着手集約 / `onDown(x,y)`
  入力 / 決着後タップでリセット / `hudInfo()` で状況表示 / `confetti()`・`banner()` 流用。
- 盤面表現は `null`=空 / `'black'` / `'white'` で gomoku と統一。
- 将来 `getOthelloCpuMove(board, color)` を差せるよう、判定は副作用なし純関数に分離する。

## 2. ルール
- 盤は **8×8 (64マス)**。石はマス内中央に配置。
- 初期配置 (黒先手): **d4=白(27) / e4=黒(28) / d5=黒(35) / e5=白(36)**
  (index = row*8 + col、a1 が左上=0)。
- 着手は「相手の石を1つ以上ひっくり返せるマスのみ合法」。8方向それぞれで、
  自分の石で挟めた相手石を全て反転する。
- **合法手が無い手番は自動パス**(相手番へ。パスした旨を banner と HUD に表示)。
- **両者とも合法手が無い (盤が埋まった場合を含む) と終局**。石数が多い方の勝ち、
  同数なら引き分け。
- スコア概念は使わず、HUD に常時 **黒●n / 白○m の石数** を文字列で表示する。

## 3. 純関数 (テスト対象・副作用なし)
すべて `index.html` 内の登録ゾーンに top-level で定義 (`?selftest` で自動実行、`window` に公開)。

| 関数 | 返り値 | 説明 |
|---|---|---|
| `othInitial()` | `board` | 初期盤面 (中央4石) |
| `getFlips(board, index, color)` | `number[]` | その手で反転するマスのindex配列。空なら非合法 |
| `getValidMoves(board, color)` | `number[]` | 合法手のindex配列 (昇順・決定的) |
| `applyMove(board, index, color)` | `newBoard` | 着手+反転を反映した**新配列** (入力不変)。非合法手は内容不変のコピー |
| `countStones(board)` | `{black, white}` | 石数集計 |
| `isGameOver(board)` | `bool` | 両者の合法手が0 |
| `getWinner(board)` | `'black'\|'white'\|'draw'` | 石数比較 |

### 自動テスト `runOthelloTests()`
初期配置 / 基本反転 / 複数方向同時反転 / 入力不変 / 非合法手 / パス(片側0手) /
終局 / 満盤の石数集計 / 引き分け / 白勝ち を網羅 (計23アサーション)。
`{pass, fail, log}` を返し、`?selftest` でコンソール出力。

## 4. UI / 描画 (W=420, H=740 基準)
- 盤: CELL=44 / BOARD=352 / BX=34 / BY=178。緑フェルト+グリッド+中央4×4角の基準点。
- 石: 黒 `●` (濃紫) / 白 `○` (生成り)。ハイライト付き。
- **合法手マーカー**: 現手番色の薄い点を候補マスに点滅表示。
- **直前着手マーカー**: 直前に置いたマスを赤リングで強調。
- **反転アニメ**: scaleX フリップ (約0.3s、視覚のみ・ロジック非干渉)。着手はポップ。
- 盤上に石数 (●n / ○m) と手番 / 結果を大きく表示。
- ボタン: プレイ中=[↩ まった] / 決着時=[▶ もう いちど][↩ まった]。

## 5. 入力 / 操作
- 入力は既存コントラクト `onDown(x,y)` で受ける (自前 addEventListener しない)。
- スマホはタップ。盤外は無視。決着後はタップでリセット (まったボタンは誤タップ救済)。
- **まった(undo)**: 直前の自分の着手 (自動パス含む) を1手戻す。盤面スナップショットで復元。

## 6. 実装範囲 (Ver1.0)
- Must: 8×8盤 / 2人交互 / 合法手判定+8方向反転 / 自動パス / 終局&石数で勝敗 /
  引き分け / リセット / 手番&石数表示 / 合法手ハイライト / スマホ対応。
- Should (実装済み): 直前着手マーカー / 反転アニメ / howto / まった。
- 非対象 (Ver1.0): CPU / オンライン対戦。

## 7. PWA / 回帰
- `index.html` を変更したため `sw.js` の `CACHE_VERSION` を上げる (`pgp2-vN` 形式)。
- 既存ゲーム (tea/lane/spot/ox/gomoku + オンライン) のコードは非改変。
  特に ox/gomoku が共有する versus 分岐の回帰を確認すること。
