## 1. 目的
五目並べに、対戦相手の選択と CPU を追加し、ヒント表示を切り替え式にする。
1. **開始時モード選択**：2人 / CPU対戦 / CPU同士
2. **CPU 3段階**（よわい・ふつう・つよい）＋ CPU対戦は**先手/後手を選択**
3. **ヒントON/OFF切り替え**（ONで常時表示、OFFで従来のオンデマンド）

前提: 既存の `getGomokuHint`・`checkGomoku`・待った/ヒントボタンは実装済み。それらを土台にする。

## 2. 方針
- gomoku ゲーム内に閉じて実装（versusコア・既存ゲームに触れない）。設定UI・ボタンは canvas 描画＋`onDown` ヒットテスト（既存パターン）。DOMオーバーレイを足す場合も既存4ゲームを壊さないこと。
- CPU思考は純関数 `getGomokuCpuMove(board, mark, level) -> index`。`getGomokuHint` を再利用して段階化。
- ★ index.html を変更するので sw.js の `CACHE_VERSION` を必ず1つ上げる。

## 3. 機能要件

### A. 開始時モード選択 — Must
- [ ] gomoku を開くと**セットアップ画面**（phase='setup'）を表示：
  - 👥 2人で対戦（PvP）
  - 🤖 CPUと対戦（PvC）→ サブ選択：**先手/後手** ＋ **強さ（よわい/ふつう/つよい）**
  - 🤖🤖 CPU同士（CvC）→ 両CPUの**強さ**を選択（左右で別々でも可。同一でもよい）
- [ ] 選択後に対局開始。リセット/もういちどは**同じ設定で再開**（設定変更はセットアップに戻る導線も用意）。

### B. CPU（3段階）— Must
- [ ] `getGomokuCpuMove(board, mark, level)` 純関数。レベル定義：
  1. **よわい**：自分が5を作れる/相手の5を止める（即詰み）だけ反応。あとは既存石近傍で中央寄りにランダム。
  2. **ふつう**：`getGomokuHint` の総合ヒューリスティック（四作り・三止め・位置評価）をそのまま使う貪欲AI。
  3. **つよい**：二重脅威（三三・四三）の創出/阻止を加点し、**1手先読み**（自分の候補→相手の最善応手まで評価）して選ぶ。
- [ ] 同点手はランダムタイブレークで対局にばらつきを出す。
- [ ] CPU着手は**思考ディレイ**（約300〜700ms、`update(dt)`のタイマー）を入れ、即時に打たない。
- [ ] CvC は自動進行（着手ごとにディレイ）。✕で中断、リセットで初期化。

### C. ヒントON/OFF切替 — Must
- [ ] ヒント表示の**トグル**を追加。ON＝手番側の良手を毎手**常時ハイライト**継続。OFF＝従来の「💡 ヒント」オンデマンド1回表示。
- [ ] PvC ではヒントは**人間の手番**に適用。CvC ではヒントは無効（or 非表示）。トグル状態は store で保持。

### 待った との整合
- [ ] PvP：従来どおり直前1手を戻す。
- [ ] PvC：「待った」は**人間の前の手番まで**戻す（CPUの応手＋自分の手の2手を取り消し、再び自分の手番に）。
- [ ] CvC：待ったは無効（淡色）。

## 4. UI/UX
- セットアップ画面・強さ/先手後手・ヒントトグルは既存トーン（cqwスケール・配色）で。
- CPU手番中は「考え中…」表示があると親切（Should）。
- ボタン群（待った/ヒント/トグル）は盤・`#btnQuit` に被らない配置。

## 5. 守ること（厳守）
- 既存5ゲーム（tea/lane/spot/ox/gomoku の既存対戦）を壊さない。回帰必須。
- コア改変は最小（基本 gomoku 内で完結）。
- sw.js の CACHE_VERSION を上げる。1ファイル方針。
- `getGomokuCpuMove`/`getGomokuHint` は純関数を維持（テスト可能）。

## 6. テスト観点
- `getGomokuCpuMove`：各レベルで「勝てる手は取る」「相手の5は止める」、つよいは二重脅威を作る/防ぐサニティ、よわいは即詰み以外はランダム範囲。
- モード：PvP/PvC(先手・後手)/CvC が開始・進行・決着する。
- ヒント：ON常時表示／OFFオンデマンド、PvCで人間手番のみ、トグル保持。
- 待った：PvP1手／PvC2手戻し（自分手番復帰）／CvC無効。
- 回帰：tea/lane/spot/ox と gomoku 既存挙動が従来通り。
- 表示：スマホでセットアップ/ボタン/ハイライトが崩れない。
