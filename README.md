# プチゲー★パーク 🎮

ブラウザで遊べる完全オリジナルのミニゲーム集。**単一HTMLファイル・依存ゼロ**。

▶ **あそぶ: https://221barisuta.github.io/petit-game-park/**

スマホはタップ/フリック、PCはクリック/ドラッグ（＋キーボード）で遊べます。

## 収録ゲーム

| ゲーム | あそびかた |
|---|---|
| 🍵 おちゃそそぎ名人 | 長押しで注いで、満タンラインぎりぎりで離す（ゲージ制御） |
| 🍣 くるくるレーン | お題に合うものだけ上フリックで取る（スワイプ仕分け） |
| 💡 スポットライト☆ダンス | 光がダンサーに重なった瞬間にタップ（タイミング） |

## ローカルで遊ぶ

`index.html` をブラウザで開くだけ。

## ミニゲームを追加する

`index.html` 内の「ミニゲーム登録ゾーン」に `registerGame({...})` ブロックを1つ追加すると、選択画面に自動で並びます。インターフェースの説明はコード内コメント参照。

効果音はすべてWebAudio合成、ベストスコアはlocalStorageに保存されます。
